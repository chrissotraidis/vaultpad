# VaultPad touch controls

VaultPad starts in **Hybrid** mode. Open the gear-and-VP badge to change the pointer mode in the VaultPad Field Terminal.

## Touch modes

| Mode | Behavior |
| --- | --- |
| Hybrid | Direct taps for play plus momentary two-finger map panning. Recommended. |
| Direct | Every one-finger tap moves the game cursor under the finger before activating the target. |
| Trackpad | Drag one finger to move the cursor, then tap to click at the cursor. |

Cursor speed affects relative Trackpad movement. Touch controls apply with **Apply & Return**; display changes apply after restarting VaultPad.

## Gestures

- One-finger tap: select, move, interact, attack, or activate the control under the finger.
- Long-press and drag: hold and drag when a legacy screen still expects it.
- Two-finger tap: displays a reminder that map panning uses a two-finger drag.
- Two-finger drag: pan the map while both fingers are down; lifting returns to the selected action without clicking objects under the cursor.
- Three-finger swipe down: Back / Escape.
- Three-finger hold: highlight nearby interactive objects.
- Four-finger hold: quicksave.

## VaultPad dock

The dock above Fallout's HUD keeps the active touch action explicit:

- **Walk / Run**: tap the ground to move. Tap the selected movement button again to switch pace.
- **Use**: tap a person, door, or object to interact. This is a direct choice, not a cycling cursor button.
- **Attack**: selects the targeting cursor and arms the next tap.
- **Current action**: shows the action name with **Normal** or **Aimed** and its action-point cost. Tap it to cycle supported attack modes.
- **Switch to**: previews and selects the alternate attack or equipped hand, then arms targeting.
- **End Turn**: appears during combat and ends the player's turn; action points refill after enemies act.
- **Gear + VP**: opens the native VaultPad Field Terminal.

Use Fallout's original **Skilldex** control for skills and its original **CMBT** control for attempting to leave combat. End Turn is intentionally duplicated because the original target is small. Choosing **VP Only** under **VaultPad Dock** hides the gameplay buttons but retains the settings badge, so the preference is always reversible.

## Display

- **Full HUD**: 640×480, preserving Fallout's 4:3 aspect and filling a 4:3 iPad with the original bottom interface. Recommended for touch.
- **More Map**: wider internal canvas with more world visible, but the original 640-pixel HUD becomes narrower and centered.

## Touch-native legacy screens

- Inventory: tap an item, then tap a hand slot or destination; repeat to move it back. Drag remains available.
- Barter: tap an item to move it between inventory and offer columns. Quantity entry opens the numeric keyboard.
- Character editor and save/load: the full visible Done and Cancel labels are touch targets.
- Dialogue: tap a response row directly.

Hardware keyboard, Magic Keyboard trackpad, Bluetooth mouse, Apple Pencil, and accessibility behavior inside the bitmap game UI are not yet certified.
